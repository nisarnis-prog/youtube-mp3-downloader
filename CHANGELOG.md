# Changelog

All notable changes to YouTube MP3 Downloader will be documented here.

## [1.0.0] - 2026-09-07

### Initial Release

- Windows desktop application built with .NET 10 and WPF.
- Support for adding multiple YouTube video URLs to a download queue.
- Configurable concurrent downloads (1-5).
- MP3 quality options: 128, 192, 256, and 320 kbps.
- Download queue management and progress tracking.
- Queue pause and resume controls.
- Built-in MP3 audio player.
- Light and dark application themes.
- Optional Chrome companion extension.
- Chrome native messaging integration.
- Windows installer with optional Chrome extension setup instructions.
